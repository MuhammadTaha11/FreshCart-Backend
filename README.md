# 🛒 FreshCart Backend

Backend API for **FreshCart**, a full-stack grocery shopping application.

## 🛠️ Technologies Used

* **Node.js** — Backend runtime
* **Fastify** — REST API framework
* **MongoDB** — Database
* **Mongoose** — MongoDB ODM
* **JWT** — User authentication
* **JavaScript** — Backend development
* **REST API** — Frontend/backend communication

## ✨ Features

* User Authentication
* Product Management
* Category Management
* Shopping Cart
* Order Management
* Protected API Routes
* MongoDB Database Integration

## 📦 Installation

```bash
npm install
```

Create a `.env` file with your MongoDB connection string and JWT secret, then run:

```bash
npm run dev
```

Built as part of the **FreshCart Full-Stack Grocery Application**.
